#ML Projects

Projects

1. House Price Prediction using Lasso Regression

Overview
A machine learning model developed to predict house prices using Lasso Regression.

#### Features

- Exploratory Data Analysis (EDA)

- Model evaluation and performance analysis

#### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
